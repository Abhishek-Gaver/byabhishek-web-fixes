QUICK ANSWERS

Before we get started.

Set expectations early so the task stays clear from request to delivery.

What do I need to send you?+

Share the relevant HTML, CSS and JavaScript files, a screenshot or short video of the issue, and a description of the expected behavior. Remove passwords and private keys first.

Will I receive the source code?+

Yes. The agreed deliverables are provided as downloadable source files. Confirm the exact files and any setup requirements in the order scope.

Can you fix any website or framework?+

This page advertises HTML, CSS and basic JavaScript work. Framework-specific tasks, backend issues, databases and complex integrations should be discussed first; they are not automatically included.

How long does a fix take?+

Timing depends on the issue and the quality of the supplied code. A delivery estimate should be confirmed after reviewing the task.
